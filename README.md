# Flowaccel

Silicon engineering leadership and workflow-acceleration consulting website for Flowaccel LLC.

## Development

```sh
bun install
bun run dev
```

Or with npm:

```sh
npm install
npm run dev
```

## Build

```sh
bun run build
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Framer Motion
